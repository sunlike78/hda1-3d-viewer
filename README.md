# HDA-1 interactive 3D viewer

Static GitHub Pages viewer for the HDA-1 domestic foamed-dough appliance main
node. It loads the reviewed STL exports directly, preserves the millimetre
coordinate system, and supports orbit, zoom, pan, cutaway, dimensions, and
per-part visibility.

The visible 11 mm pressure-shell wall and 12 mm bottom are P0 visualization
placeholders, not production dimensions. Pressure boundary, welds, lid, and
lock require a separate code calculation and physical validation.
