# HDA-1 / P2 — предварительный комплект документации

## Главный файл

`hda1_p2_preliminary_documentation_package_ru.pdf` — единый PDF-пакет:

1. титул и статус;
2. состав и границы проработки;
3. техническая архитектура;
4. ведомость основных узлов;
5. расчётная сводка;
6. программа верификации;
7. актуальный сборочный лист GA-03;
8. мобильная обзорная страница с 3D-рендером.

## CAD-источник

`../drawings/hda1_p2_ga03_preliminary_ru_v4.dxf` — нативный DXF R2013, лист A3, масштаб 1:2. Он открывается в LibreCAD, Autodesk Viewer и других DXF-совместимых системах.

## Статус

Это **предварительная конструкторская проработка P2**. Она не является:

- серийной рабочей конструкторской документацией;
- нормированным расчётом сосуда под давлением;
- сертификатом безопасности;
- разрешением на самостоятельное изготовление или эксплуатацию под давлением.

Перед переходом к прототипу нужны финальная параметрическая 3D-CAD-модель, расчёт камеры/крышки/замка по применимой норме, FEM и ресурс, подбор серийных компонентов и физические испытания.
