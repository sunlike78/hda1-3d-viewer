# HDA-1 / P2 — предварительный пакет документации

## Главный файл

`hda1_p2_preliminary_documentation_package_ru.pdf` — единый проверенный PDF на 15 страниц:

1. титул, границы проработки и техническая архитектура;
2. ведомость узлов, расчётная сводка и программа верификации;
3. расчёты вала, привода, муфты, подшипников, подачи воздуха, давления, замка и декомпрессии;
4. трассируемость расчётов и ограничения;
5. сборочный лист GA-03 и мобильная обзорная страница с 3D-рендером;
6. GA-06 — подробные проекции и разрезы P2: экранная копия, полученная из нативного DXF экспортом LibreCAD;
7. приложение с фактическим CAD-рендером контрольного разреза из FreeCAD.

## Исходники CAD

- `HDA1_P2_Master.FCStd` — параметрическая сборка FreeCAD 1.1.3;
- `HDA1_P2_Master.step` — обменная BRep-модель STEP;
- `hda1_p2_ga06_detailed_projections_ru.dxf` — нативный исходник подробного листа GA-06;
- `hda1_p2_ga06_librecad_export.pdf` — прямой экспорт DXF из LibreCAD;
- `hda1_p2_ga06_screen_copy_ru.pdf` — проверенная компоновка GA-06, включённая в единый пакет;
- `hda1_p2_freecad_cutaway.png` — CAD-рендер контрольного разреза.

Конструктивное правило, проверяемое во всех материалах: форма имеет сплошное дно, нижней опоры вала в чаше нет; вал поддержан только верхней сухой головкой. Красный элемент на рендере — независимый механический предохранительный клапан.

## Проверки

Выполнены независимые численные проверки расчётов (вал/привод/подшипники, подача воздуха/нагрузка замка) и проверка нативной BRep-модели FreeCAD: 22 объекта, в том числе две твёрдотельные ленты, с ненулевыми объёмами и соблюдением отсутствия нижней опоры в чаше. Визуально проверены лист GA-06 и CAD-разрез, включённые в PDF.

## Статус

Это предварительная конструкторская проработка P2, а не рабочая документация для изготовления сосуда под давлением. Перед прототипом нужны нормируемый расчёт камеры, крышки и замка, FEM/ресурс, подбор серийных компонентов и физические испытания.
