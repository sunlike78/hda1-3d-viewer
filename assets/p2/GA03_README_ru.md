# GA-03 — актуальный CAD-лист

`hda1_p2_ga03_preliminary_ru.dxf` — лист A3 в DXF R2013.

Проверен открытием в LibreCAD 2.2.1.5: русские подписи читаются штатным
шрифтом `cyrillic_ii.lff`; виды, размерные цепи и текстовые зоны разнесены.
`hda1_p2_ga03_mobile_preview_ru.pdf` построен из той же DXF-геометрии для
быстрого просмотра на телефоне.

Статус: предконструкторская проработка P2, не документация для изготовления.
