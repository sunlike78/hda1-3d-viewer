# HDA-1 / P2 — предварительный пакет документации

## Главный файл

`hda1_p2_preliminary_documentation_package_ru.pdf` — единый проверенный PDF на 15 страниц:

1. титул, границы проработки и техническая архитектура;
2. ведомость узлов, расчётная сводка и программа верификации;
3. расчёты вала, привода, муфты, подшипников, подачи воздуха, давления, замка и декомпрессии;
4. трассируемость расчётов и ограничения;
5. сборочный лист GA-03 и мобильная обзорная страница с 3D-рендером;
6. GA-05 — подробный сборочный reference-лист, построенный по параметрам нативной модели FreeCAD;
7. приложение с фактическим CAD-рендером из FreeCAD.

## Нативная CAD-модель

- `../freecad/HDA1_P2_Master.FCStd` — исходная параметрическая сборка FreeCAD 1.1.3;
- `../freecad/HDA1_P2_Master.step` — обменная модель STEP;
- `../freecad/HDA1_P2_GA05_Detailed_Reference.pdf` — отдельный лист GA-05;
- `../freecad/HDA1_P2_CAD_Cutaway.png` — CAD-рендер контрольного разреза.

Конструктивное правило, проверяемое во всех материалах: форма имеет сплошное дно, нижней опоры вала в чаше нет; вал поддержан только верхней сухой головкой. Красный элемент на рендере — независимый механический предохранительный клапан.

## Статус

Это предварительная конструкторская проработка P2, а не рабочая документация для изготовления сосуда под давлением. Перед прототипом нужны нормируемый расчёт камеры, крышки и замка, FEM/ресурс, подбор серийных компонентов и физические испытания.
