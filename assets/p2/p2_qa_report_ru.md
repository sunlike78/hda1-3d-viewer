# HDA-1 — цифровая QA-проверка P2

Дата: 28.07.2026. Проверка относится к цифровой модели и визуальным материалам P2; она не заменяет физические испытания.

## 1. Экспорт параметрической сборки

- Источник: `main_node_p2.scad`.
- Экспорт: `scripts/render_p2.ps1`.
- Выгружено 12 STL: камера, слив, P2-форма, крышка, уплотнение, кольцо, кассета уплотнения, экран, вал, мешалка, порты, двигатель.
- Экспорт завершён без диагностических ошибок OpenSCAD.

## 2. Проверка STL

`tools/validate_stl.py` подтвердил для P2:

- конечные координаты и ненулевые грани;
- замкнутые поверхности (каждое ребро принадлежит двум граням);
- корректную ориентацию общих рёбер;
- ненулевые объёмы компонентов;
- цельную связную мешалку P2-B: 3 012 треугольников, без предупреждений;
- цельную связную P2-форму: 908 треугольников, без предупреждений.

У нескольких сборочных STL (уплотнение, шпиндель, порты) несколько связных компонентов ожидаемы, потому что это экспорт визуально разделённых подсборок; каждый компонент замкнут.

## 3. Контроль геометрических инвариантов

`calculations/p2_geometry_checks.js` — PASS:

| Проверка | Результат |
|---|---:|
| Объём формы в диапазоне 1,2–1,8 л | 1,679 л |
| Радиальный зазор мешалка–форма ≥7 мм | 7,989 мм |
| Зазор до дна ≥7 мм | 8,0 мм |
| Нижняя опора отсутствует | PASS |
| Верх мешалки остаётся ниже нижней плоскости крышки | 16,5 мм запаса |
| Диаметр мокрого вала | Ø20 мм |

Именно этот контроль обнаружил несоответствие с ранней конической P1-формой. P2-форма была изменена на постоянный Ø150 мм до финального экспорта.

## 4. Визуальная QA

- P2-сборка отрендерена в Blender Cycles GPU (AMD Radeon 780M), 1200 × 900, 32 samples, adaptive + OIDN.
- Проверены: отсутствие нижней опоры, читаемость съёмной формы и верхнего вала, отдельный красный предохранительный клапан, наличие кольцевого замка, отсутствие «лент Мёбиуса» или разорванной геометрии.
- GA-02 сформирован как SVG, отрендерен в PNG и вручную просмотрен. На листе нет стрелочных выносок, указывающих не на детали; смысловые пояснения вынесены в текстовые блоки.

## 5. Намеренно не заявляется как завершённое

1. Эффективность вспенивания и качество выпечки — требуют 54 физических циклов.
2. FEM, усталость, сварка, герметизация и расчёт сосуда по нормам — требуют инженера по оборудованию под давлением.
3. Реальная настройка аварийного клапана, расход сброса и электробезопасность — требуют поставщиков и испытаний.

P2 цифрово согласован; его функциональная валидность пока не доказана и этим документом не подменяется.
