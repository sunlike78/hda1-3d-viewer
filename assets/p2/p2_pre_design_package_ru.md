# HDA-1 — пакет P2 для прототипа главного узла

**Версия:** P2 / 28.07.2026  
**Назначение:** предконструкторская база для функционального прототипа бытовой машины на 350–500 г аэрированного теста.  
**Статус:** не является серийной КД, расчётом сосуда по нормам, сертификатом или разрешением на самостоятельное изготовление сосуда под давлением.

## 1. Что изменилось по сравнению с P1

- Убран художественный гибрид лопастей без доказанной функции.
- Появилась P2-форма с постоянным внутренним Ø150 мм, высотой 95 мм и объёмом 1,679 л.
- Новая мешалка имеет реальный параметрический контур: две открытые ленточные спирали и исследовательское щелевое кольцо.
- Подтверждены цифровые зазоры: 7,989 мм по радиусу и 8,0 мм до цельного дна.
- Вал приведён к Ø20 мм; введены расчётные пределы 12 Н·м длительно / 24 Н·м кратковременно.
- Рабочее давление не объявлено заранее: +20 / +40 / +60 кПа — только стендовые точки исследования.

## 4. Требования к прототипу

1. Вал, инструмент и форма не получают нижней опоры.
2. Крышка не разблокируется по одному датчику или только программой.
3. Рабочий и предохранительный выпуск не объединяются после камеры.
4. Запуск под давлением запрещён при неопознанной форме, неустановленной мешалке, рассогласовании P1/P2 или ненулевых RPM.
5. Нагрузка выше 24 Н·м прекращает замес до прессуризации.
6. Форма, инструмент, экран и уплотнение снимаются без ключа и остаются визуально проверяемыми.

## 5. Ворота перехода P2 → физический прототип

- 54 тестовых цикла по матрице A/B × 20/40/60 кПа × 3 профиля сброса × 3 повтора;
- выбрана одна рецептура для первого окна, без маркетинговых медицинских обещаний;
- результат повторяется минимум в 9 из 10 циклов;
- измерены момент, температура, давление, объём/плотность, оседание и структура после выпечки;
- до давления выше стендового диапазона выполнены профессиональный расчёт, гидроиспытание и валидация клапана.
