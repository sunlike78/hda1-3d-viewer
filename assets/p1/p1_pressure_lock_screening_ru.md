# HDA-1 P1 — предварительный расчёт силовой оболочки и замка

Дата: 27.07.2026. Расчёт предназначен для выбора разумной **геометрии P1**
перед FEA и расчётом по нормам. Он не является расчётом сосуда по EN 13445 и
не даёт права на изготовление или маркировку CE.

## Зафиксированные исходные условия P1

| Параметр | Принято |
|---|---:|
| Нормальная работа | до +0,15 МПа |
| Расчётное давление PS | +0,25 МПа |
| Предварительное гидроиспытание | +0,325 МПа |
| Расчётная температура | до 60 °C |
| Внутренний диаметр камеры | 210 мм |
| Расчётный объём оболочки | около 4,92 л |
| Материал-кандидат оболочки | 1.4404 / 316L |
| Принятая условная допускаемая величина | 115 МПа |
| Условный коэффициент сварного соединения | 0,85 |

При PS = 2,5 бар и объёме 4,92 л произведение PS·V составляет около
12,3 бар·л. Это не классификация по PED: она зависит от окончательной
конфигурации, группы среды, объёма, защитной арматуры и трактовки всего
изделия. Однако давление выше 0,5 бар уже попадает в область PED.

## Оболочка

Для первичного скрининга использована тонкостенная окружная мембранная модель:

`t = p·D / (2·f·η − p)`.

При +0,25 МПа расчётный мембранный минимум получается около **0,27 мм**, при
+0,325 МПа — около **0,35 мм**. Эти числа нельзя использовать как толщину
детали: в них нет минимальной технологической толщины, допуска проката,
формовки днища, сварных переходов, штуцеров, локальных концентраций,
усталости и коррозионного/полировочного припуска.

Для P1 принята **номинальная стенка 2,5 мм** и нижнее днище 3,0 мм с отдельным
верхним фланцем. Окружное напряжение такой оболочки составляет ориентировочно
6,3 МПа в нормальном режиме, 10,5 МПа при PS и 13,7 МПа при
гидроиспытании. Это только sanity check, а не доказательство прочности.

## Крышка

Крышка P1 — не массивный 28-мм цилиндр P0, а 10-мм верхняя несущая плита,
опирающаяся на кольцевой фланец. Упрощённая формула жёстко защемлённой круглой
пластины Ø210 мм даёт около 11,4 МПа при PS и 14,8 МПа при гидроиспытании.

В финальном расчёте обязательны: центральное отверстие под вращающееся
уплотнение, локальные контактные давления прокладки, жёсткость фланца,
деформация кольца и FEA.

## Поворотный замок

Принято 8 зацепов, каждый с толщиной 7 мм и длиной зацепления 18 мм.

| Проверка при гидроиспытании | Значение |
|---|---:|
| Сила от давления на Ø210 мм | 11,26 кН |
| Предварительное обжатие прокладки | 1,00 кН |
| Полная расчётная сила замка | 12,26 кН |
| На один из 8 зацепов | 1,53 кН |
| Площадь среза одного зацепа | 126 мм² |
| Среднее касательное напряжение | 12,2 МПа |
| Условный запас к 65 МПа | 5,3 |

Это только средний срез. До выпуска P1 в металл нужны контактный расчёт,
изгиб каждого зацепа, допуски поворотного кольца, усталость, защита от
самооткрывания, испытания предельной нагрузки и независимая блокировка при
ненулевом давлении.

## Обязательные ворота перед прототипом

1. Утвердить PS, TS, среду, объём и маршрут соответствия с ответственным
   инженером по оборудованию под давлением.
2. Выполнить EN 13445 / применимый расчёт камеры, днища, крышки, фланца,
   штуцеров, сварки и замка.
3. Выбрать сертифицированный предохранительный клапан с уставкой не выше PS,
   независимый от управляемого выпуска.
4. Провести гидроиспытание, проверку герметичности, ресурсные циклы замка,
   аварийный сброс и FMEA.

Нормативная граница: PED 2014/68/EU применяется к оборудованию с PS выше
0,5 бар. См. официальную [страницу Европейской комиссии](https://single-market-economy.ec.europa.eu/single-market/goods/european-standards/harmonised-standards/pressure-equipment_en) и [текст директивы](https://eur-lex.europa.eu/legal-content/EN/TXT/?qid=1782329382909&uri=CELEX%3A02014L0068).
